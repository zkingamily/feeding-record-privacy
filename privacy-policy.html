隐私政策

生效日期：2026年2月20日

感谢您使用母乳喂养记录应用（以下简称"本应用"）。我们重视您的隐私和信息安全。本隐私政策说明了我们如何收集、使用、存储和保护您的信息。

1. 收集的信息

1.1 您主动提供的信息

  • 喂养记录：开始时间、结束时间、持续时长、备注
  • 用户账户信息（如使用登录功能）：手机号或邮箱、验证码

1.2 自动收集的信息

  • 设备信息：设备型号、操作系统版本
  • 应用使用数据：功能使用频率、崩溃日志

1.3 不收集的信息

  • 我们不收集位置信息、相机、通讯录等敏感权限
  • 我们不收集用户的个人身份信息（除非用户主动登录）

2. 信息使用

我们收集的信息仅用于以下目的：

  • 功能提供：记录和管理您的喂养数据
  • 数据持久化：在您的设备上本地存储数据
  • 应用改进：分析应用性能和用户体验
  • 错误修复：诊断和修复应用问题
  • 用户支持：回复您的咨询和反馈

3. 数据存储与安全

3.1 数据存储位置

  • 本地存储：您的所有喂养记录都存储在您的设备本地
  • 云存储（如启用登录功能）：数据可能同步到服务器进行备份

3.2 数据安全措施

  • 使用 HTTPS/TLS 加密传输网络数据
  • 本地数据采用操作系统提供的安全存储方案
  • 定期安全审查和更新

3.3 数据保留期限

  • 本地数据：由您控制，您可随时删除
  • 服务器数据：按照您的账户设置保留或删除

4. 第三方服务

本应用可能使用以下第三方服务：

服务 用途 隐私政策
iOS/Android 操作系统 系统功能支持 Apple/Google 隐私政策
Dio HTTP 库 网络请求 开源库，无数据收集
SharedPreferences 本地数据存储 开源库，本地存储

5. 用户权利

您有权：

  • 访问权：了解我们收集了哪些您的数据
  • 更正权：修改不准确的数据
  • 删除权：随时删除您的喂养记录和账户
  • 撤回权：撤回对数据收集的同意
  • 投诉权：向相关部门投诉我们的数据处理

6. 儿童隐私保护

本应用可能被用于记录婴幼儿的喂养信息。我们：

  • 不会向儿童或其监护人直接收集个人信息
  • 数据仅供家长/监护人使用
  • 不会与第三方商业机构共享儿童数据
  • 遵守适用的儿童在线隐私保护法规

7. 数据共享与披露

7.1 不共享个人数据

我们不会将您的个人数据共享给：

  • 广告商或营销机构
  • 数据分析公司
  • 任何第三方商业实体

7.2 法律要求的例外

在以下情况下，我们可能披露数据：

  • 法院命令或政府要求
  • 维护本应用的合法权益
  • 保护用户和公众的安全

8. 隐私政策更新

我们可能不时更新本隐私政策以反映法律变化或我们的实践变化。

  • 重要变更：将通过应用通知告知您
  • 您继续使用本应用表示接受更新的政策

9. 联系我们

如对本隐私政策有任何疑问或建议，请通过以下方式联系我们：

  • 邮箱：hilici@126.com
  • 应用反馈：在应用内使用反馈功能

10. 合规声明

本应用遵守以下法规：

  • 中国《个人信息保护法》（PIPL）
  • 欧盟《通用数据保护条例》（GDPR）基本要求
  • 美国《儿童在线隐私保护法》（COPPA）
  • Apple App Store 隐私政策要求

快速概览

✓ 不收集敏感信息：不访问位置、相机、通讯录等

✓ 本地数据存储：您的喂养记录仅存储在您的设备上

✓ 不共享数据：不向第三方或广告商共享您的数据

✓ 数据安全：使用加密保护网络通信

✓ 您可随时删除：数据完全由您控制
